# Website Toko Daging Zainuddin

Website statis untuk memperkenalkan produk Toko Daging Zainuddin serta memudahkan calon pelanggan melihat pilihan produk dan menghubungi toko untuk pemesanan.

## Fitur

- Halaman beranda dan informasi toko.
- Katalog pilihan daging dengan foto dan harga.
- Navigasi ke bagian produk, tentang, dan kontak.
- Tombol pemesanan melalui WhatsApp.
- Menu responsif untuk layar kecil.
- Interaksi navigasi dan smooth scrolling dengan JavaScript.

## Teknologi

- HTML
- CSS
- JavaScript
- Font Awesome

## Struktur Proyek

- `index.html`: struktur dan konten halaman.
- `styles.css`: tampilan, layout, dan responsivitas.
- `script.js`: interaksi navigasi.
- `img/`: foto produk dan aset visual.

## Menjalankan

Website tidak membutuhkan database atau proses build. Buka `index.html` menggunakan browser. Untuk pengembangan, buka folder di Visual Studio Code dan gunakan Live Server.

## Catatan

Periksa kembali foto, harga, dan tautan kontak sebelum website dipublikasikan. Saat ini website berfungsi sebagai katalog dan penghubung pemesanan, belum sebagai toko online dengan keranjang atau pembayaran digital.
